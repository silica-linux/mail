## Toolbar

Left to right: reply (disabled in a new message), the format toggle ("Aa", on), emoji and
symbols, writing tools, a header-fields pop-up, an attachments pop-up, a third pop-up, and
Send at the right end.

## Fields

- To is a token field: a finished address turns into a blue capsule with a chevron.
- From is a pop-up with the sender's name and address.

## Format bar

Paragraph style pop-up, font family, font style, size (default 12), text colour well,
highlight colour, bold / italic / underline / strikethrough segments, a list pop-up and
indent buttons.

## Closing a changed message

⌘W on a composer with changes shows an alert **292 × 254**: a question whether to keep the
message as a draft, and three stacked full-width buttons:

| Button | Look |
| --- | --- |
| Save | blue, default |
| Don't save | red text on a pale red capsule; discards the message (no draft left) |
| Cancel | plain |
