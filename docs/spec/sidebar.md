## Sections

Top to bottom: favourites, smart mailboxes, local mailboxes ("on this computer"), then one
section per account. While a search is active an extra section appears at the very top
with an "all mailboxes" entry.

## Behaviour

- Flagging a message for the first time adds a Flagged mailbox to the favourites.
- Opening a composer for the first time adds Drafts (`mailboxDrafts`) to the favourites.
- Both stay after the app quits.
