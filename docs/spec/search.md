# Search

Session ML-01, light.

- Typing in the search field opens a suggestion menu under it: the typed text completed,
  then "sender contains", "subject contains" and "attachment name contains" entries, each
  with a small glyph (`senderContains`, `subjectContains`).
- Results replace the list. The title block shows `searching` with `searchScope` under it
  (all mailboxes and the number of results).
- Results come in two groups: best matches first, then all results.
- Matching text is highlighted in yellow; each row shows its mailbox name next to the date.
- A button to save the search as a smart mailbox appears next to the filter.
- Choosing a "… contains" suggestion turns the text into a token: a small gray capsule
  with the field name in capitals and a chevron (`tokenSubject`, `tokenSender`) before the
  text.
- The sidebar gains a search section at the top while searching ([sidebar.md](sidebar.md)).
- Exact colours of the highlight and token: *unmeasured*.
